1. Mục tiêu và phạm vi

Mục tiêu là xây dựng lớp API công khai cho website IronForge Machinery mà không thay đổi đáng kể luồng web và trang quản trị hiện có. API phục vụ frontend, ứng dụng di động hoặc hệ thống bên thứ ba.

  • Giữ nguyên model, migration, controller web và giao diện Blade.
  • Tách API theo namespace App\Http\Controllers\Api\V1.
  • Chuẩn hóa JSON bằng Laravel API Resource.
  • Validation và giới hạn tần suất cho endpoint gửi yêu cầu.
  • Kiểm thử bằng SQLite in-memory, không tác động database thật.

2. Công nghệ và kiến trúc

Dự án sử dụng PHP 8.2+, Laravel 11, Eloquent ORM và PHPUnit 11. API được phiên bản hóa để có thể mở rộng mà không phá vỡ client đang sử dụng.

Luồng xử lý: HTTP Request → routes/api.php → API Controller → Eloquent Model → API Resource → JSON Response.

2.1. Thành phần bổ sung

  • routes/api.php: khai báo 11 endpoint.
  • app/Http/Controllers/Api/V1: truy vấn, lọc, phân trang.
  • app/Http/Resources/Api/V1: định dạng JSON nhất quán.
  • bootstrap/app.php: đăng ký API routes trong Laravel 11.
  • tests/Feature/Api/V1/ApiTest.php: kiểm thử tích hợp.

4. Chức năng chính

4.1. Truy vấn và phân trang

Các danh sách dùng paginator. per_page được giới hạn 1–100. Sản phẩm hỗ trợ search, category, featured; bài viết hỗ trợ search.

4.2. Route model binding

Endpoint chi tiết dùng slug. Laravel tự tìm bản ghi và trả HTTP 404 khi không tồn tại.

4.3. Validation và an toàn dữ liệu

POST /inquiries tái sử dụng StoreInquiryRequest, áp dụng throttle 30 request/phút và trả HTTP 201 khi tạo thành công.

4.4. Kiểm soát nội dung công khai

API chỉ trả bài đã xuất bản, đánh giá đang hiển thị và nhóm setting cần cho giao diện.

5. Bằng chứng triển khai và kiểm thử

6. Bằng chứng phản hồi JSON

Laravel được chạy cục bộ với database SQLite minh chứng riêng. Request GET /api/v1/products?per_page=1 trả cấu trúc data, links và meta.

7. Hướng dẫn kiểm thử lại

php artisan migrate --seed
php artisan serve
php artisan test --filter=ApiTest

Invoke-RestMethod http://127.0.0.1:8000/api/v1/products

Trong Postman, đặt base URL là http://127.0.0.1:8000/api/v1. Với POST /inquiries, gửi JSON gồm name, phone, email và message.

8. Kết luận

API v1 được tích hợp theo hướng ít xâm lấn: không thay đổi schema dữ liệu, không sửa luồng web/admin và tái sử dụng model cùng validation hiện có. Kết quả kiểm thử xác nhận endpoint hoạt động đúng, dữ liệu công khai được kiểm soát và phản hồi có cấu trúc JSON nhất quán.
